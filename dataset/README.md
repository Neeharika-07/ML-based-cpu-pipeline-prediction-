# PipelineAI Dataset Guide

## 1. Overview
The dataset consists of CPU instruction execution branch traces captured across 10 distinct benchmark programs (traces 0 through 9).

- Total dynamic branches in raw trace: **200,160 branches** (10 traces $\times$ 20,016 branches)
- Total ML-ready processed branches: **200,000 branches** (10 traces $\times$ 20,000 branches, after dropping 16 warmup branches per trace)

---

## 2. File Specifications

### `raw_dataset.csv`
Contains raw execution logs directly from CPU profiling:
- `trace_num`: Benchmark trace identifier (integer from 0 to 9).
- `branch_index`: Sequence number of branch in program execution order (0 to 20,015).
- `pc`: 64-bit Program Counter memory address of the branch instruction.
- `taken`: Ground truth outcome (`1` = Taken, `0` = Not Taken).
*Note*: The first 16 branches of each trace do not have a PC entry as they represent warmup states before global history registers fill.

### `processed_dataset.csv`
Numerical ML-ready matrix generated by `ml/preprocessing.py`:
- `trace_num`: Benchmark trace identifier (0 to 9) *(metadata, do not use as feature)*.
- `branch_index`: Execution sequence number *(metadata, do not use as feature)*.
- `split`: Chronological partition *(0 = Train [first 14,000], 1 = Val [next 3,000], 2 = Test [last 3,000])*.
- `pc_idx`: `pc % 4096` — 12-bit hashed branch address (Feature 1).
- `h1` through `h16`: 16 binary history features representing outcomes of the preceding 16 branches (Features 2 through 17).
- `label`: Target binary outcome (`1` = Taken, `0` = Not Taken).

---

## 3. Dataset Distribution Summary
- **Overall Class Balance**:
  - `Not Taken (0)`: ~61.77%
  - `Taken (1)`: ~38.23%
- **Partition Sizes**:
  - `Train (split=0)`: 140,000 rows
  - `Val (split=1)`: 30,000 rows
  - `Test (split=2)`: 30,000 rows
